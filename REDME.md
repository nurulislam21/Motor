# Motor

**Motor** is a simple and flexible Arduino library for controlling dual H-bridge motor drivers. It's designed for use in robotics and automation projects using platforms like Arduino, STM32 and ESP32.

---pio

## 🚀 Features

- Control two DC motors independently
- Simple API with intuitive operator overloading
- Supports custom pin assignments- Designed for BTS7960 motor drivers
- Lightweight and efficient
